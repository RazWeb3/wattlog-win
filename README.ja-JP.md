# wattlog

**Windows ノートPCの、実測によるバッテリー消費・充電ワット数。**

wattlog は作業中のシステム全体の消費電力（W）、バッテリー残量、累積ワット時を
数秒間隔でサンプリングし、グラフ・貼り付け用の表・自動取得した端末情報をまとめた
**自己完結型の HTML レポート**を生成します。
ゼロインストール：ファイル2つ、管理者権限不要、ネット接続不要、MITライセンス。

```
放電 · 80% → 65% · 57分 · 平均 7.9 W
```

[English](README.md) | 日本語

## 計測できること — そして正直に「できないこと」

| | |
|---|---|
| **計測する** | 放電中**と**充電中のシステム全体W · 電池残量の推移 · %/h と 1%あたりの分 · 累積Wh · 充電の回復率 · 計測条件 · 端末スペック |
| **計測しない** | アプリ別の電力内訳 — Windows は正確なプロセス単位ワット数を報告しないため、wattlog は推測をしません。NPU/GPU の稼働率カウンター — ベンダーごとに名称が違いすぎるため |

アプリを1つだけ動かせば、システム全体W がそのままその構成の消費電力です。
単一アプリの寄与分が欲しいなら、アイドルのベースラインを計測して引いてください。

W の取得は2経路：ドライバーが対応していればバッテリー自身の充放電レート、
そうでなければ `容量 × 残量変化 ÷ 経過時間`。フォールバックは残量が読める機種なら動きます。

## 標準のバッテリーレポートやハードウェアモニタではダメなのか？

`powercfg /batteryreport` は無料で内蔵ツールなので、そのまま使い続けてください。
ただしこれは*履歴からの推定*です。wattlog が存在するのはできない側の用途、
**自分で選んだシナリオを、レビュー対象の機種で、条件を添えて計測し**、
公開できるグラフまで出すことです。HWiNFO64 は優秀ですが無料枠は非商用ライセンス。
wattlog は MIT です。

## クイックスタート

1. テストしたいノートPCにこのフォルダをコピー（zip でも USB でも OK。インストーラーはありません）。
2. `wattlog.cmd` をダブルクリックすると4択が出るので、放電か充電 × 残量で止めるか時間
   で止めるかを選びます。
   ```
   1) 放電（バッテリー駆動）: 残量 10.0%（既定） で自動停止
   2) 放電（バッテリー駆動）: 時間を指定して自動停止／残量 10.0%（既定） に達したらその時点で終了
   3) 充電（電源接続）: 残量 100.0%（既定） または充電完了で自動停止
   4) 充電（電源接続）: 時間を指定して自動停止／残量 100.0%（既定）・充電完了でその時点で終了
   ```
   経過時間を聞かれるのは 2 と 4 を選んだときだけ。そのあとに計測条件のメモを1問
   （Enter でスキップ）。表示される閾値は実際に効く値なので、`wattlog.conf` や `-StopAt`
   で変えてあればその値と出所がそのまま出ます。
   分数は数字だけ入れます（1時間なら `60`）。空 Enter は「時間停止なし」の明示的な選択、
   数字以外なら警告してもう一度聞き、3回続けて不正なら計測を開始せずに終了します。
3. 計測したい作業をします。設定した閾値（既定：残量10%）で自動停止するので、
   テスト中にそのまま電源が落ちることはありません。
4. 生成された HTML を開いて**スクショ用**ボタンを押して公開。CSV は同じ場所に保存されます。

```
:: 放電: 動画再生、残量10%で停止
powershell -NoProfile -ExecutionPolicy Bypass -File logger.ps1 -Mode discharge -Interval 5 -StopAt 10 -Note "輝度60%、音量20、WiFi on"

:: 充電: 10分間
powershell -NoProfile -ExecutionPolicy Bypass -File logger.ps1 -Mode charge -Interval 5 -Duration 10

:: 既存CSVから HTML だけ再生成（再計測不要）
powershell -NoProfile -ExecutionPolicy Bypass -File logger.ps1 -FromCsv logs\wattlog-discharge-20261003-091417-menu.csv
```

### オプション

| フラグ | 意味 |
|---|---|
| `-Mode discharge\|charge` | 計測モード（付けると4択メニューを省略して即開始） |
| `-Interval s` | サンプリング間隔、既定 5 秒 |
| `-StopAt %` | 自動停止の閾値 — 放電は以下、充電は以上で停止（既定 10 / 100） |
| `-Duration min` | N 分経過で停止 |
| `-Note text` | 計測条件の自由メモ（音量/WiFi/バックグラウンド等）。電源プランと画面輝度は自動取得 |
| `-Label text` | 出力ファイル名の接尾辞 |
| `-Out dir` | 出力先（既定 `logs`、絶対パス可） |
| `-KeepAwake on\|off` | 計測中のスリープ防止（既定 on） |
| `-FromCsv csv` | 計測をスキップし、既存CSVから HTML を再生成 |
| `-Lang en\|ja` | ツールUIとレポートの言語（既定は Windows の表示言語） |
| `-Conf path` | 読み込む設定ファイル（既定は `logger.ps1` と同階層の `wattlog.conf`。無ければ何もしない） |

### 設定ファイル（wattlog.conf）

毎回同じフラグを打つのが面倒なら、`wattlog.conf.sample` を `logger.ps1` と同じ階層に
`wattlog.conf` としてコピーし、1行1項の `key=value`（`#` でコメント・UTF-8保存）で書きます。

```
interval=5
duration=60
stopat=10
```

優先順位は **コマンドライン引数 > wattlog.conf > メニュー入力 > 組み込み既定**。
打った引数が常にファイルに勝つので、ファイル置いたまま例外運用もできます。
書ける鍵は `interval` / `stopat` / `duration` / `out` / `label` / `keepawake` / `lang`。

`mode` と `note` は意図的に設定ファイルの対象外にしています。 放電か充電か・計測条件は回ごとに変わるため、
ファイルに固定せず毎回明示してもらいます（結果の誠実さを守るため）。

値が不正なら、既定に黙って戻さずエラーで停止します（`duration` のタイプミスで
「止まるはずが止まらなかった」を作るのが一番危ないため）。
不明な鍵・空値・`key=value` でない行はその行だけ、行番号付きの警告を出して無視します。

実際に効いた設定は CSV 先頭に記録されるので、いつ計測したものでも再現できます。

```
# params: mode=discharge interval=5.0 stopat=10.0 duration=60.0 keepawake=on lang=ja source=duration:conf
# config: C:\tools\wattlog\wattlog.conf
```

`source=` は既定値で**ない**項目だけ（`cli` / `conf` / `menu` 付き）を列挙し、
`# config:` 行は設定ファイルが効いた計測のときだけ書かれます。

## レポートの内容

- **グラフ** — 電池残量（0〜100% 固定）、瞬時消費電力（約1分窓の移動中央値で表示。
  生ログには単発のドライバースパイクが含まれるため。ホバーと範囲選択の統計は生値のまま）、
  累積 Wh。
- **区間統計** — 始点をクリック→終点をクリックで、その区間の平均W・Δ%・%/h・ΔWh・Wh/h。
  ドラッグ選択もできます。
- **貼り付け用の表** — 15分/30分/1時間刻みの表を、リッチテキストで WordPress（ビジュアルエディタ）に
  そのまま、または HTML マークアップでコピーできます。
- **スクショ用モード** — ボタン1つで操作UIをすべて隠し、サイドバーのクリップも解除するので、
  ページ全体のキャプチャに全部写ります。Esc で解除。
- **端末情報の自動記録** — 機種名、OSビルド、CPU（コア/スレッド）、RAM、GPU、
  解像度+リフレッシュレート、ディスク種別、NPU の有無、バッテリーサイクル数。
  一般ユーザー権限で CIM/レジストリから読み、読めない項目は黙って省略します。
- **日本語・英語UI** — メニュー、コンソール、レポートの言語は Windows の表示言語に追従し、
  `-Lang en|ja` で強制もできます。CSV のデータは言語に依存しないので、
  記録済みのどの CSVからも両言語で再生成できます：
  `logger.ps1 -FromCsv logs\run.csv -Lang ja`。
- **自己完結** — HTML 1枚、SVG/JS インライン。ディスクや USB から開くだけで動き、
  依存関係はありません。データがどこかへ送信されることも一切ありません。

## 動作環境

- Windows 10 / 11（バッテリー搭載機。デスクトップ機は対象外）
- PowerShell 5.1（Windows 内蔵版。`wattlog.cmd` が起動を処理します）
- 管理者権限不要・ネット接続不要・依存なし

## 制限事項

- スリープ防止は計測セッション中のみ。蓋閉じの挙動は電源プランに従います
  （確実にしたい場合は `powercfg` の LIDACTION を設定してください）。
- 充電W はベンダーの充電コントローラー依存のため、セッション開始直後に数秒の
  ランプアップノイズが出ます（CSV にはそのまま記録、グラフ側で平滑化）。
- 瞬時W はウィンドウ単位の精度です。ミリ秒単位の過渡的なスパイクは捉えません。
